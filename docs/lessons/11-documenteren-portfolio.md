# Les 11 — Documenteren en een portfolio onderhouden

## Wat goede documentatie bevat
- Doel van het project.
- Vereisten en gebruikte technologieën.
- Mappenstructuur.
- Commando's om te bouwen, starten en testen.
- Verwachte resultaten.
- Bekende problemen en oplossingen.
- Wat ik geleerd heb en wat ik nog wil leren.

## GitHub-portfolio
Een portfolio moet eerlijk weergeven wat werkt en wat ik zelf heb uitgevoerd. Noteer AI-gebruik transparant: ChatGPT kan helpen uitleggen en documenteren, terwijl ik de commando's uitvoer, de uitkomsten controleer en de werking probeer te begrijpen.

## Publicatiecontrole
```bash
git status
git diff
git diff --staged
```

Controleer voor elke commit dat er geen geheimen, persoonlijke gegevens of onbedoelde bestanden worden gepubliceerd.
