# Les 1 — WSL2 en Ubuntu

## Doel
Begrijpen hoe ik Linux-commando's uitvoer vanuit Ubuntu op Windows.

## Begrippen
- **WSL2** laat een Linux-omgeving naast Windows draaien.
- **Terminal** is de tekstinterface waarin ik commando's uitvoer.
- **Shell** (bijvoorbeeld Bash) leest commando's en voert ze uit.
- `~` verwijst naar de home directory van de huidige gebruiker.

## Commando's
```bash
pwd
whoami
ls
cd ~/projects
```

- `pwd`: toont de huidige map.
- `whoami`: toont de huidige Linux-gebruiker.
- `ls`: toont bestanden en mappen.
- `cd`: verandert de huidige map.

## Proces
1. Open Ubuntu.
2. Controleer de huidige locatie met `pwd`.
3. Ga naar de projectmap met `cd`.
4. Controleer de inhoud met `ls`.

## Oefening
Navigeer naar je project en controleer of je in de juiste map staat voordat je Git- of Docker-commando's uitvoert.
