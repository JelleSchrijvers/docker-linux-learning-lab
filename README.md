# Linux & Docker Learning Lab

## About This Project

This repository documents my learning journey into Linux, Docker, and containerized application development.

I am learning Linux using Ubuntu on WSL2 (Windows Subsystem for Linux 2) and practicing Docker in a Linux environment. I use a hands-on approach by running commands, building containers, testing applications, solving problems, and documenting what I learn.

## Why I Started This Project

I believe AI is changing the way people learn, solve problems, and develop technical skills. Rather than avoiding these tools, I want to learn how to use them effectively to improve my learning process.

I chose to learn Linux and Docker with the help of AI because it gives me an interactive way to ask questions, explore unfamiliar concepts, practice new skills, and get guidance when I encounter problems.

My goal is to make learning more efficient while developing a genuine understanding of the technologies I use. I see AI not as a replacement for learning, but as a tool that can help me learn faster, explore different approaches, and become more independent over time.

I am documenting this journey publicly to track my progress, share what I learn, and demonstrate how I combine AI-assisted learning with hands-on technical practice.

## Technologies

- Ubuntu on WSL2
- Linux command line
- Docker and Dockerfiles
- C# and ASP.NET Core
- .NET 10
- Git and GitHub

## Current Progress

- Practiced Linux navigation and basic file operations.
- Learned to create, start, stop, inspect, and remove Docker containers.
- Built a simple ASP.NET Core Web API.
- Created a multi-stage Dockerfile to build and publish the application.
- Built a Docker image and ran the API inside a container.
- Tested the API endpoint using curl.
- Started learning Git and preparing this project for version control.

## How I Use AI

I use ChatGPT as an AI learning assistant throughout this project. It helps me understand Linux commands, learn Docker concepts, work through practical exercises, troubleshoot issues, and explore different solutions.

I run commands and test the resulting applications in my own Ubuntu environment on WSL2. I aim to understand what each command does, why a particular solution works, and what its limitations are, rather than blindly copying instructions.

This repository is an honest record of my learning process, including the use of AI as part of that process.

## Learning Goals

- Become more confident using Linux and the command line.
- Understand Docker images, containers, volumes, networks, and Docker Compose.
- Build and containerize applications with .NET.

- Explore automated testing and CI/CD with GitHub Actions.
- Build a practical end-to-end project that demonstrates my progress.
