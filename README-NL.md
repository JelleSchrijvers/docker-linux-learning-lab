# Linux & Docker Learning Lab

Mijn persoonlijke leeromgeving om Linux, Git, GitHub, .NET en Docker stap voor stap te leren door dingen zelf uit te voeren en te testen.

## Doel

Ik leer de basis van development en DevOps door een kleine .NET Web API te bouwen, lokaal te testen, in een Docker-container te draaien en mijn werk met Git en GitHub te beheren.

## Repository-indeling

- `src/DockerDemo/` — broncode van de .NET Web API.
- `docs/lessons/` — lesnotities en concepten.
- `docs/processes/` — herhaalbare stappenplannen.
- `docs/troubleshooting/` — fouten, oorzaken en oplossingen.
- `scripts/` — optionele hulpscripts.
- `LESSON-INDEX.md` — centrale lesindex.

## Technologieën

- Ubuntu via WSL2
- Git en GitHub
- .NET / ASP.NET Core
- Docker
- Bash en de Linux-terminal

## Werkwijze

1. Lees de relevante les of procesbeschrijving.
2. Voer de commando's zelf uit in je eigen omgeving.
3. Controleer de uitvoer en test of het resultaat klopt.
4. Noteer fouten en oplossingen.
5. Commit betekenisvolle wijzigingen met Git.

## Gebruik van AI

Ik gebruik ChatGPT als leerassistent om concepten en commando's uit te leggen, mogelijke fouten te onderzoeken en documentatie te structureren. Ik voer commando's zelf uit, controleer de resultaten en werk eraan om te begrijpen wat ze doen.

## Status

De eerste versie van de .NET Web API is lokaal getest en succesvol in Docker uitgevoerd. De Git-repository is gepubliceerd op GitHub. De documentatie wordt verder aangevuld terwijl ik nieuwe onderwerpen leer.

## Belangrijk

Plaats geen wachtwoorden, access tokens, private keys, connection strings met echte credentials of andere geheimen in deze repository. Controleer wijzigingen met `git status` voordat je commit.
